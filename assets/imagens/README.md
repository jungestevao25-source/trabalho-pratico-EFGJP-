# Imagens (`assets/imagens/`)

Pasta destinada a sprites e elementos visuais do jogo.

## Conteúdo atual

- `carro_jogador.png`: sprite do veículo controlado pelo jogador (vista de cima, 70×100 px).
- `carro_obstaculo.png`: sprite dos veículos obstáculos que descem pela pista (70×100 px).

## Recomendações

- Separe imagens por tema quando o projeto crescer.
- Mantenha dimensões e padrões consistentes para facilitar colisão e animação.
- Prefira formatos com transparência (`.png`) para sprites sobre fundos dinâmicos.
- Documente a origem das imagens quando forem de terceiros.

## Origem dos assets

Os sprites `carro_jogador.png` e `carro_obstaculo.png` foram obtidos de banco de imagens gratuito para uso não-comercial.
