# TOP RACE — Projeto Pygame

Pequeno jogo de corrida/top-down desenvolvido para o trabalho prático.

Como rodar

1. Instale dependências (recomendado criar um virtualenv):

```bash
pip install -r requirements.txt
```

2. Execute o jogo:

```bash
python main.py
```

Estrutura e entregas

- `docs/proposta.MD`: proposta do jogo (Semana 1) — preenchida.
- `main.py` e `src/`: código do jogo com loop, controles, obstáculos (Semanas 2–4).
- `tests/`: testes unitários para lógica básica.

Dependências principais:

- `pygame` — para a janela e lógica gráfica.
- `pytest` — para executar os testes.
